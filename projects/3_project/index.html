A tool to help find suitable native plant species using species reports and calculating connectivity measures and how it changes by planting out the species in a selected location. Possible to rank species e.g. based on its relevance for biodiversity or nectar production. In swedish only. [https://linussoderquist.github.io/vaxtval/] (https://linussoderquist.github.io/vaxtval/)
